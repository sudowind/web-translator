# PDF 论文标题统一展示

工作台左上角和管理页面优先展示已解析的论文标题，缺少可靠标题时保留源标题／文件名。使用首页开头的一级标题，合并标题内部换行；摘要、目录、引言、编号章节和页眉信息不能作为论文标题。不为标题额外调用模型或重新解析。

新解析文档在规范化时保存标题；历史文档读取时用已有首页块补齐，历史列表读取或更新时同步保存展示标题。晚到的文件名更新不得覆盖已知标题。标题随阅读记录保留，清除解析缓存不删除已保存的历史标题。无需升级数据库或更改文档版本。

本轮仍在 release 人工验收周期内；独立 feature 从 master 创建，修复提交后普通合入 release。验证覆盖标题选择、无标题回退、旧缓存、历史同步和清缓存后的保留；独立复核后执行最终门禁。

## 旧缓存未识别标题的补充修复

用户报告 arXiv 2510.12403 刷新仍显示文件名。官方 citation_title 已核验为 Robot Learning: A Tutorial；用户浏览器连接不可用，不能宣称已读到其缓存。原规则仅接收开头一级标题，缺少该层级或排列不同的旧结果没有兜底。

对仍是文件名的缓存，工作台异步请求独立的标题补齐接口。后台只请求固定 arxiv.org/abs/论文编号，校验 citation_arxiv_id，限制响应 256KB 和 4 秒超时，不带 cookie、不跟随重定向。不调用模型或重新解析。标题保存到原文档及已有历史；UI 使用独立标题状态，不替换全文模型，不重启翻译调度，不阻塞阅读恢复。清缓存后的迟到结果受 generation 隔离。网络失败保留原文件名。
