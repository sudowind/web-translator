# 网页语义块对照翻译

## 目标与范围

按标题、段落、列表项、引用及通用容器中的连续行内内容分块，原文保持不动，在对应内容之后显示译文。嵌套列表和引用按内部段落分块，父子块不重复。翻译方向沿用用户设置，扫描不限制英文字母。

## 渲染与协议

原有逐文本节点替换方案由本规格取代。原文节点、事件、属性均不修改。译文使用插件拥有的块级 span；插在原文连续内容之后、下一段结构之前，不复制列表编号或交互控件。

每个块序列化为完整句段，行内元素使用成对标记 `⟦wt:0⟧…⟦/wt:0⟧`，换行和受保护的行内代码使用单独标记 `⟦wt:0/⟧`。后台只发送文本和标记，模型不得生成 HTML。客户端校验标记数量、配对、嵌套与原结构一致，再由本地白名单生成元素。仅复制安全链接及字体、字号、颜色、行高等文字样式，不复制 id、事件、脚本、页面 class 或任意 HTML。标记错误显示可重试状态，不应用错误格式。

跳过编辑区、表单控件、脚本、代码块、隐藏内容、SVG、插件节点；行内代码保留原样。超出单块接口上限时显示明确失败并保持原文，暂不拆散语义块。

## 生命周期

监听新增、移除、文本更新和影响可见性、格式及链接的属性更新；合并突发更新后统一协调当前块。每次内容或结构变更生成新请求标识，旧结果不得回写。移动块保留有效译文并调整位置，删除源块移除译文，重复启用和插件自身插入不重复请求。关闭先停止观察和队列、取消后台请求，再删除所有自有节点；不恢复旧原文覆盖网站的新内容。

## 验收

- 完整句段在包含加粗、斜体、链接时仍作为一次翻译输入，嵌套列表无重复。
- 译文紧随对应内容，文字样式与安全链接保留，原文及事件不变。
- 动态文本、元素替换、移除、移动、隐藏、链接变化和请求竞态均有回归测试。
- 授权后的独立浏览器 E2E 验证 DOM、计算样式和交互；不冒充真实 action Popup、activeTab 或原生权限验收。

## 兼容边界

本轮不处理 iframe、Shadow DOM 内部、Canvas 文字或复杂站点专用布局适配。独立浏览器测试使用模拟 Provider，不调用用户付费接口。
