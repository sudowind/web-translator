# 阅读控制台字号与阅读密度优化

## 范围与方向

面向桌面浏览器中的翻译用户，让设置、帮助说明和历史记录无需额外缩放即可阅读。仅调整 options 样式和进度条展示结构，不修改权限、数据结构、翻译或 Provider 行为。

延续现有阅读控制台：墨蓝 #172033、画布灰 #eef1f6、纸白 #fbfcfe、强调蓝 #315efb、边线灰 #d8dee9、辅助灰 #596579。辅助标题使用更深的文字蓝 #284ed4，保证灰色画布上的对比度。保留宋体/Georgia 衬线标题与系统无衬线正文，补齐微软雅黑、苹方中文回退，等宽字体仅用于分类标识。特色仍是阅读记录与进度，不引入营销式首页、远程字体或新依赖。

## 字号与布局

- 根字号使用 100%，body 显式使用 1rem，防止扩展页默认正文样式缩小字号。默认正文 16px、行高 1.6；表单标签和操作按钮 16px；辅助说明、导航副文案、元数据不小于 14px。
- 历史标题和表单分组标题 18px；页面标题桌面 40px，窄屏 32px，使用 rem、行高 1.5，保留标题字形并给中文字体留足垂直空间。
- 正文列保持最大 920px；桌面侧栏，较窄窗口顶部换行导航。配置网格依可用空间自动换行，长标题和域名允许断行。
- 进度条与页码分开布局，页码进入正常文档流，避免旧版绝对定位越过卡片边界。
- 控件至少 44px 高，随字号增长；不使用整页 zoom/transform，也不通过隐藏溢出来掩盖布局问题。操作栏不覆盖正文。

## 验收

真实构建扩展在隔离 Playwright 浏览器加载，使用虚构历史记录，不读取用户现有配置。覆盖五个分区、1440/1024/768/375px 宽度、100% 与 200% 根字号文本缩放；检查字号、布局溢出、长文本、文字对比度、表单编辑与保存校验、搜索与键盘焦点，并输出截图。实际保存授权不在本次样式自动化范围内。

200% 根字号模拟仅代表文本缩放，不冒充 Chrome 原生页面缩放验收。原生缩放和已安装扩展重载由 release 人工验收。

## 方案复核

frontend-design 要求保留与阅读主题有关的文字层级；ui-ux-pro-max 搜索结果包含营销首页与新配色，不适合本次局部修正，故仅采用可读性、对比度、焦点和响应式检查。16px 是此次产品基线，不宣称是统一强制规范。
