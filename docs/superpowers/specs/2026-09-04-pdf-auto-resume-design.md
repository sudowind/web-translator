# PDF 翻译状态与阅读位置自动恢复

日期：2026-09-04
状态：dev 实现与定向验证完成，待协调任务集成 release

## 现状

解析与译文缓存已存在，但工作台运行时注入不随刷新保留；后台没有按文档持久化启用状态。release 历史记录包含阅读页码，但工作台初始化只读取 URL 页码，未串起普通 URL 的恢复路径。

## 行为

- 用户成功启用后记住此 PDF 的启用状态；刷新及重新打开时恢复工作台。主动关闭先持久化关闭，再恢复原页面，防止重新加载循环。
- 记录页码、页内比例和缩放，初始化先读取记录再挂载阅读器。明确的 `#page=N` 优先于记忆位置；页数改变时限制在有效页内。
- arXiv PDF 以带版本的论文身份区分，忽略非文档查询参数；不自动接管 abs 摘要 HTML。普通 HTTP(S) URL 保留完整查询参数、去掉片段后作为身份。存储键使用身份摘要，不另外保存包含签名的原始 URL。
- 启用标志与阅读位置使用独立 chrome.storage.local 记录，不改变 IndexedDB 版本，不绑定译文缓存的 Provider 或模型，不把阅读位置更新当成再次启用。
- 仅对曾启用、当前仍为 PDF 且浏览器允许访问的文档自动注入。自动流程不申请权限。用户在 Popup 点击启用时可请求当前站点的可选权限；拒绝不妨碍本次 activeTab 手动使用，但重新打开的自动恢复可能不可用。不得申请所有站点权限。
- 自动接管绑定预检得到的 documentId，导航后不注入新页面；同标签页恢复串行，关闭与导航使未提交的恢复失效。HTTP(S) 普通浏览器环境为本轮范围，不对本地文件或隐身页面持久恢复。
- 认证 PDF 仍需原有上传同意，不持久化上传授权。自动恢复可能继续原来的按需翻译调度，已有译文命中缓存；不扩展为全站自动翻译。
- 阅读状态消息限定主框架和发送者 documentId；导航代际在异步状态验证后、存储提交前再次检查，旧页面不能借同 URL 新页面的状态覆盖进度。200 ms 滚动防抖写入，pagehide 尽力补存；立即关闭/刷新时浏览器可能终止末次消息，最近已经持久化的位置仍可恢复。

## 验收

定向覆盖键隔离、状态持久化与并发、关闭、权限拒绝、非 PDF、导航竞态、页码优先级及比例。独立 Chromium 授权测试覆盖刷新与新标签页无需再次 enable、阅读位置恢复、关闭后刷新不重启、其他 URL 不启用、缓存无重复翻译。真实 Popup/原生权限弹窗由人工验收，不以授权测试代替。

本任务只在 dev 实现、测试与提交，完成后通知协调任务；release 合并、冲突、完整门禁及验收构建由协调任务处理。
