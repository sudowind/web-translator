# 论文库首版设计

新增控制台「论文库」分区，提供浏览器收藏夹式的论文管理。收藏入口为 PDF 工作台星标和最近阅读中的 PDF 行；名称可编辑，目录默认记住上次选择，首次使用「未分类」。一篇论文只有一个收藏位置；按规范化 URL（arXiv 保留版本）去重。文件夹支持嵌套、新建、重命名和删除，不提供拖拽、标签、笔记、阅读状态、回收站、导入导出和 AI 能力。

左侧文件夹树，右侧当前目录的直接收藏；「全部论文」展示全部收藏，搜索名称时覆盖整个论文库。可编辑收藏名称、移动目录、取消收藏、重新打开论文。打开时优先使用最新历史页码，清历史后仍可复用已有 PDF 阅读恢复。删除文件夹需确认，原子删除子目录及其中收藏，不影响历史、解析或译文缓存。清历史和缓存不影响收藏。

使用 IndexedDB v6 新增 bookmarks、bookmarkFolders、libraryPreferences 三个存储，不改变既有记录。收藏保存 URL、名称、收藏时间和收藏时页码（仅作记录，不用于覆盖阅读恢复）；默认目录单独持久化。收藏管理消息只允许控制台，PDF 工作台仅允许已验证的顶层挂载页面读取库、新建目录和管理当前 URL 的收藏，不能操作其他论文或删除目录。界面沿用后台及工作台样式；失败显示原因并保留表单。

验收覆盖旧数据库迁移、重复收藏、嵌套删除、默认目录回退、缓存隔离、非法来源/消息、两个收藏入口、重启持久化、移动搜索与页码打开。生产构建仅在 release 主工作区生成验收版本，用户重载原扩展后人工验收。
