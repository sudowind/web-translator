# 扩展独立控制台与翻译历史设计

日期：2026-09-03  
状态：已完成

## 1. 背景

当前 Provider 设置通过扩展 `options` 入口提供，但构建产物使用 `options_ui.open_in_tab: false`。从 Popup 或 PDF 工作台调用 `browser.runtime.openOptionsPage()` 时，Chrome 可能把设置页嵌入扩展管理界面，用户需要离开当前工作流。现有设置页还是单列长表单，无法承载最近阅读、缓存管理和后续偏好设置。

项目已经在 IndexedDB 中保存 PDF 文档模型、逐页译文、解析任务和阅读位置，但这些数据用于运行时缓存，尚未形成独立、可查询的插件使用历史。普通网页翻译也没有持久化历史记录。

## 2. 目标

1. 把扩展设置作为独立标签页打开，不再嵌入 `chrome://extensions`。
2. 将现有 options 页升级为统一控制台，提供最近阅读、AI 服务、翻译偏好、PDF 解析和存储隐私分区。
3. 仅记录用户主动使用插件翻译过的 PDF 与普通网页，不读取 Chrome 全局浏览历史。
4. PDF 历史保存最近阅读页和总页数；网页历史保存最近一次成功翻译时间。
5. 支持搜索、类型筛选、重新打开、删除单条历史、清空历史、清空运行缓存。
6. 历史与缓存使用独立存储和删除语义，清缓存不再等同于删除历史。
7. Provider 凭据继续只保存在扩展本地，且不进入历史、日志或页面 URL。

## 3. 非目标

- 不申请 Chrome `history` 权限，不读取用户未使用插件翻译的网页。
- 不提供账号、云同步、多设备历史或远程管理网站。
- 不缓存普通网页正文、译文正文、表单内容或用户选区。
- 不自动接管从历史重新打开的 PDF；重新打开只恢复原 URL 与页码，是否启用工作台仍由用户决定。
- 不在本轮统计精确字节占用；存储页只展示各类记录数量和清理操作。

## 4. 页面与入口

WXT options 入口增加 `wxt.openInTab=true`，构建为独立扩展标签页。Popup 保留“翻译当前页面”的短任务，并把原“Provider 设置”入口改为“打开控制台”。PDF 工作台的“设置”继续调用 options 入口。

控制台使用单页内分区，不引入路由依赖：

- 最近阅读：默认分区，展示历史列表、搜索和类型筛选。
- AI 服务：LLM Provider、API Key、默认模型和智能体设置。
- 翻译偏好：源语言、目标语言、翻译超时和对应连接测试。
- PDF 解析：MinerU 地址、模型、Token 和配置检查。
- 存储与隐私：本地存储说明、记录数量、清空历史和清空缓存。

桌面布局为固定侧栏加内容区；窄屏改为顶部横向分区导航。视觉延续 PDF 工作台的编辑型极简：冷灰纸面、深墨文字、靛蓝操作色和克制的状态色。历史列表采用连续“阅读账本”而非卡片网格，标题、时间、阅读进度和动作形成稳定行节奏。

## 5. 历史数据模型

IndexedDB 升级到版本 4，新增 `history` 存储，包含记录类型、URL、标题、语言、最近访问时间、可选文档 hash 和 PDF 阅读进度。版本 3 由并行实施的 arXiv 源标识映射占用；两个分支集成时必须保留 v3 `sources` 与 v4 `history` 两段顺序迁移。`history` 建立 `by-last-visited` 与 `by-kind` 索引，仓储提供新增或合并、按最近时间列出、删除单条、清空历史和存储概览。

## 6. 写入时机

普通网页在首批文本成功翻译后，由后台从可信 `MessageSender.tab` 读取 URL 和标题并写入历史。PDF 工作台取得源描述后上报访问记录，活动页或总页数变化时节流更新进度。历史写入失败不得中断阅读或翻译。

## 7. 删除语义

- 删除历史只删除 `history` 记录，不删除文档模型和译文缓存。
- 清空缓存只清理 documents、translations、tasks 与 reading，不清理 history。
- 不在本轮提供混合删除凭据的“恢复出厂设置”。

## 8. 安全与隐私

- 后台只接受真实标签页发出的 PDF 历史写入请求。
- URL 只允许 HTTP(S)，长度受限；标题和语言字段长度受限。
- 设置测试继续只允许扩展 options 页面调用，但允许该页面带查询参数或 Fragment。
- 历史页面不显示 API Key、Token、网页正文、译文正文或 Provider 请求内容。

## 9. 验收标准

- 构建产物包含 `options_ui.open_in_tab: true`。
- Popup 可一键打开独立控制台；现有 Provider 保存与测试功能不回退。
- PDF 与网页各完成一次插件翻译后出现在最近阅读，按最近时间倒序。
- PDF 页面变化更新历史进度，重新打开 URL 带正确页码。
- 历史支持搜索、类型筛选、单条删除和清空。
- 清空缓存后历史仍保留；清空历史后 PDF 缓存仍可命中。
- 未授权页面无法调用控制台管理接口或设置测试。
- 定向单元测试、类型检查、构建验证和完整 `npm run check` 通过。
