# PDF 现代编辑型极简界面设计

## 背景

当前 PDF 工作台的功能已经覆盖 PDF.js 渲染、MinerU 解析、逐页翻译、公式与 Markdown、区块联动、缓存、失败诊断和论文智能体。但界面仍大量依赖“白色卡片、灰色边框、圆角按钮”表达层级：工具栏中的所有操作同权展示，PDF 与译文分别被边框包围，译文区块、媒体占位和智能体消息继续嵌套卡片。最终效果更像调试后台，而不是适合长时间阅读论文的现代阅读器。

本次设计采用用户确认的 A 方案“编辑型极简”，以内容、留白、字体层级和少量主题色建立界面结构。功能和阅读模型保持不变，只调整视觉层级、操作组织、智能体展开方式和译文密度。

## 目标

- 显著减少外框、圆角卡片、虚线框和重复分隔条。
- 建立统一的“学术靛蓝”主题色，替换现有黄色区块高亮。
- 保留 PDF 与译文逐页配对、严格等高和单主滚动体验。
- 让译文略微紧凑，同时保持中文长文阅读的舒适度。
- 将顶部工具栏从操作堆叠改为清晰的主次分组。
- 智能体默认关闭，展开后在桌面端参与布局，不遮挡译文。
- 保留键盘操作、焦点可见性、失败恢复和响应式行为。

## 非目标

- 不修改 MinerU、LLM、缓存、逐页翻译调度和智能体上下文逻辑。
- 不改变 PDF 页面与对应译文块的等高约束。
- 不取消长译文在单页内部的溢出滚动。
- 不新增深色模式；本次通过语义化颜色变量为后续主题扩展保留基础。
- 不引入远程字体、整套 UI 组件库或新的图标运行时依赖。
- 不重新设计插件设置页和普通网页翻译界面。

## 方案比较

### 方案 A：编辑型极简

通过留白、排版和少量阴影建立层级，PDF 纸张、译文正文和智能体拥有明确但克制的视觉关系。该方案最适合论文阅读，对现有组件结构改动可控。

### 方案 B：沉浸式画布

使用悬浮工具栏、浮动智能体入口和更明显的纸张表面。产品感更强，但浮层较多，容易打断长时间阅读。

### 方案 C：精密工作台

使用工具轨、分栏线和高密度状态区，接近专业编辑器。操作效率高，但工具感仍强，不符合减少“框框块块”的主要目标。

采用方案 A。

## 视觉原则

### 内容优先

PDF 页面和译文是视觉主体。界面控件、状态和容器边界必须退居次要层级，不能与论文内容竞争注意力。

### 用空间建立层级

默认不为结构容器增加边框和圆角。相关内容通过间距聚合，不同层级通过字号、字重、背景明度和必要的单条分隔线区分。

### 单一强调色

“学术靛蓝”只用于可交互状态、焦点、页码引用、当前区块联动和智能体激活状态。错误继续使用红色语义，不用主题色冒充错误或成功状态。

### 动效克制

只对背景色、透明度和轻微位移使用 120–180ms 过渡。Agent 展开引发的网格重排不动画宽度，避免 PDF 重新测量期间出现抖动。继续尊重 `prefers-reduced-motion`。

## 色彩系统

首版使用浅色主题，并将颜色集中为语义变量：

| 变量 | 建议值 | 用途 |
|---|---:|---|
| `--pdf-primary` | `#4f46e5` | 主交互、当前区块、Agent 激活 |
| `--pdf-primary-hover` | `#4338ca` | 主交互悬停 |
| `--pdf-primary-soft` | `#eef2ff` | 轻量悬停、用户消息背景 |
| `--pdf-primary-muted` | `#e0e7ff` | 固定区块和引用弱强调 |
| `--pdf-canvas-bg` | `#f3f4f6` | 整体阅读画布 |
| `--pdf-surface` | `#ffffff` | PDF 纸张、译文和 Agent 表面 |
| `--pdf-text` | `#111827` | 主文本 |
| `--pdf-text-muted` | `#667085` | 页码、状态和次要说明 |
| `--pdf-divider` | `#e5e7eb` | 必要的单线分隔 |
| `--pdf-error` | `#b42318` | 错误文本和失败状态 |

禁止继续使用黄色或琥珀色表达区块联动。主题色也不应用到大面积背景、普通标题和正文文字。

## 页面结构

```text
PDF 工作台
├── sticky 极简工具栏
├── 条件状态提示（仅解析、失败等必要状态出现）
└── 工作区
    ├── 逐页阅读流
    │   ├── 第 1 页：PDF 纸张 + 译文
    │   ├── 第 2 页：PDF 纸张 + 译文
    │   └── …
    └── Agent 面板（默认不存在，展开后成为第三列）
```

收起状态不再保留 180px 的 Agent 占位列，也不显示窄入口或悬浮球。工具栏中的“论文智能体”按钮是唯一的全局开关。

## 顶部工具栏

工具栏保持 sticky 和至少 44×44px 的交互热区，但按钮的可见外形可以更轻量。内容按以下顺序组织：

- 左侧：论文标题，单行省略。
- 中部：当前页/总页数、缩小、放大。
- 右侧：紧凑翻译进度、“论文智能体”开关、“更多”菜单。

“重试当前页”“重试失败页”“重试解析”“取消当前任务”“清理本文缓存”“设置”和“关闭工作台”进入“更多”菜单。失败或存在可重试页时，可以在进度区域显示明显但不扩张布局的错误提示。

工具栏不再让每个操作都使用相同的描边按钮。普通图标或文字按钮使用透明背景，悬停时出现 `--pdf-primary-soft` 状态层；智能体展开时按钮使用主题色和 `aria-expanded="true"` 表达状态。

## 状态提示

常规“已完成 N 页、翻译中 N 页”等信息合并到工具栏的紧凑进度区域，不再永久占用独立横条。

以下状态才在工具栏下方显示条件提示：

- MinerU 正在解析或等待上传同意；
- PDF 或 MinerU 解析失败；
- 多页翻译失败，需要用户采取恢复操作；
- 缓存清理等需要短暂确认的操作。

错误提示必须保留原因和恢复入口，但默认诊断详情仍收起。

## PDF 阅读区

- 删除 `.page-pair-pdf` 的外框和圆角容器感。
- 阅读区使用中性浅灰画布，PDF Canvas 本身使用白色纸张和一档轻阴影。
- 每页之间使用稳定的 24px 左右垂直间距，不用额外卡片分隔。
- PDF Canvas、文本层和区块高亮层的尺寸与渲染逻辑保持不变。
- 非渲染窗口页面继续使用稳定高度占位，避免滚动跳动。

PDF 原文区块联动改为靛蓝色弱高亮：

- 悬停预览：约 10%–14% 主题色填充和 1px 主题色边界。
- 固定状态：约 16% 主题色填充和更明确的 1.5px 边界。
- 删除现有黄色填充、棕色描边和白色双重外发光。
- 文本框选继续使用独立的系统蓝色选区，避免与区块固定状态完全相同。

## 译文页面

译文保留与 PDF 页面等高的外层和内部溢出滚动，但移除明显的整页卡片外框。

### 页级元信息

- “第 N 页”和状态使用 13px 左右的次要文字。
- 删除页头底部分隔线。
- 页头与正文之间只保留约 10–12px 间距。
- “完成”保持中性色，不使用绿色胶囊。

### 适度紧凑的正文

- 正文保持约 15–16px，不通过缩小字号换取密度。
- 正文行高从当前约 `1.65` 调整到 `1.6–1.62`。
- 译文页内边距从 20px 调整到约 16px；宽屏可保持 16–18px。
- 普通区块内边距从 8px 调整到约 4–6px。
- 区块间距和普通段落垂直间距缩小约 25%。
- 标题仍按 MinerU 层级显示，但收紧标题上下间距。
- 独立公式保留居中和横向溢出能力，垂直留白缩小到约 10–12px。

### 区块交互

- 默认区块没有边框、背景和圆角卡片感。
- 可映射区块悬停时只显示约 5%–7% 的主题色背景。
- 固定区块使用约 10% 的主题色背景和左侧 2px 靛蓝强调线。
- 不再显示额外的“已固定”胶囊；通过视觉状态和 `aria-pressed` 表达固定状态。
- 键盘焦点继续使用清晰的 2–3px 焦点环，不能只依靠背景色。

### 图片与表格占位

- 删除虚线边框、整块灰底和胶囊标签。
- 改为最小高度约 48–52px 的轻量信息行。
- 使用短竖线或统一线性图标标明“图片”或“表格”，右侧显示翻译后的标题。
- 无标题、翻译中和失败继续显示明确文字状态。
- 只有错误状态可以使用弱红色背景，正常占位不形成新卡片。

## 论文智能体

### 开关

- 初始状态为关闭。
- 工具栏中的“论文智能体”按钮是唯一全局入口。
- 关闭时 Agent 完全不占工作区宽度，不保留窄栏、浮动按钮或空白列。
- 展开后按钮显示激活状态，并设置 `aria-expanded="true"`。
- Agent 标题栏提供“收起”按钮，与工具栏按钮执行同一状态切换。

### 桌面展开

- Agent 作为宽约 340–360px 的第三列参与工作区网格布局。
- 面板不得覆盖 PDF 或译文。
- 阅读区按剩余空间重新计算 PDF/译文比例。
- 当阅读区无法维持两列最小可读宽度时，单个页对切换为 PDF 在上、译文在下，不允许通过覆盖译文换取 Agent 空间。
- Agent 展开时不显示遮罩，不动画网格宽度。

### 面板内部

- Agent 是右侧连续表面，通过左侧一条分隔线与阅读区区分，不再表现为圆角卡片。
- 标题栏 sticky，输入区固定在面板底部，消息区独立滚动。
- 用户消息可以使用 `--pdf-primary-soft` 的轻背景。
- 助手回答直接排版在面板背景上，不再套灰色消息卡片。
- Markdown、公式、表格和页码引用继续使用现有渲染能力。

### 极窄窗口

在无法同时容纳阅读区和 Agent 的极窄窗口下，Agent 可切换为全屏临时问答面板。此行为必须有明确标题和关闭按钮，属于显式的“问答模式”，不能伪装成桌面常态。

## 响应式规则

- 宽屏：PDF/译文两列，Agent 展开后成为第三列。
- 中等宽度：Agent 仍为独立列；当主阅读区不足时，页对改为上下布局。
- 窄屏：PDF 和译文上下排列；Agent 使用全屏临时面板。
- 工具栏保持单行，逐步隐藏次要文字标签，但不缩小交互热区。
- 页面不得产生横向滚动，也不能因 Agent 展开遮挡译文。

## 无障碍

- 所有工具栏和 Agent 操作保持至少 44×44px 的可点击区域。
- 图标按钮提供可访问名称；“更多”菜单使用正确的展开状态。
- Agent 开关使用 `aria-expanded` 和可见激活状态。
- 区块固定使用 `aria-pressed`，同时用背景和左侧强调线表达，避免只依赖颜色。
- 普通文本与背景对比度至少达到 WCAG AA。
- 键盘焦点始终可见，不移除系统或自定义焦点环。
- 动态进度使用 `aria-live="polite"`，失败继续使用 `role="alert"`。

## 组件调整边界

预计涉及以下现有组件和样式边界：

- `PdfWorkspace`：工具栏分组、更多菜单、条件状态、Agent 默认状态和工作区类名。
- `PairedPageViewer` / `PagePair`：移除页对外框视觉，不改变页高和可见窗口逻辑。
- `TranslationPage` / `TranslationBlock`：紧凑排版、页级元信息、靛蓝联动和媒体信息行。
- `PdfBlockHighlightLayer`：替换黄色高亮视觉，不改变 MinerU polygon 映射。
- `AgentPanel`：连续侧栏布局、消息样式、底部输入区和关闭按钮。
- `style.css`：建立语义化 token、工具栏、响应式和 reduced-motion 规则。

不在本次改动中拆分业务状态管理或重写翻译调度。

## 测试策略

### 定向单元与组件测试

- Agent 默认关闭，关闭时工作区不存在占位列。
- 工具栏 Agent 按钮与面板标题栏按钮同步切换，并正确更新 `aria-expanded`。
- 次要操作进入更多菜单，现有回调仍能触发。
- 译文区块继续支持 hover、focus、点击固定和键盘固定。
- 媒体占位继续显示标题翻译和无标题/翻译中/失败状态。
- PDF 文本层、公式、Markdown 和页码引用无回归。

### 样式约束测试

- PDF/译文页对不再使用明显外框。
- 代码中不再使用黄色或琥珀色作为区块联动颜色。
- Agent 收起布局不保留 180px 列。
- 长译文仍具有内部 `overflow-y: auto`，PDF/译文外层仍等高。
- `prefers-reduced-motion` 下禁用非必要过渡。

### E2E 与视觉验证

- 宽屏 Agent 关闭：极简工具栏、无多余状态条、PDF/译文无外框套框。
- 宽屏 Agent 展开：面板成为第三列且不遮挡译文。
- 中等宽度 Agent 展开：页对按规则切换布局且无横向滚动。
- 紧凑译文：标题、段落、公式、图片/表格占位和失败详情均保持可读。
- 靛蓝联动：悬停与固定状态在 PDF 和译文两侧一致，文本框选仍可辨识。
- 现有滚动稳定性、Canvas 可见窗口和逐页等高断言继续通过。

## 验收标准

- 页面不再依赖多层边框、卡片和虚线框表达结构。
- 顶部工具栏只直接展示高频操作，次要操作收纳到更多菜单。
- 常规翻译进度不再占用永久状态条。
- PDF 纸张只有轻阴影，不存在额外卡片外框。
- 译文视觉密度有所提高，但正文字号不减小，公式和标题仍清晰。
- 所有黄色区块高亮替换为统一的学术靛蓝联动状态。
- Agent 默认关闭且不占宽度；桌面展开后不遮挡译文。
- PDF/译文逐页等高、单主滚动、长译文内部滚动和文本框选保持正确。
- 宽屏、中等宽度和窄屏均无意外横向滚动或不可达操作。
- 相关单元测试、组件测试、`npm run check` 和 PDF 工作台 E2E 最终门禁通过。
