# PDF 工作台夜间主题与原稿柔和暗化设计

日期：2026-09-03  
状态：已批准并实现

## 1. 目标

为 PDF 翻译工作台提供“跟随系统、浅色、深色”三档外观设置。工作台自行渲染的工具栏、译文、智能体、表格、代码块与状态反馈使用完整深色配色；PDF.js Canvas 保留原稿颜色关系，只在深色模式下执行柔和暗化。

本规格覆盖此前“本轮不新增深色模式”的阶段性限制，后续以本规格为准。

## 2. 设计原则

- 学术阅读优先：避免纯黑背景、纯白正文和高饱和装饰色，长时间阅读时保持稳定层级。
- 原稿与界面分治：自渲染界面使用真正的深色变量；PDF 位图不反相，不重绘，不改变文本层坐标。
- 明确可控：用户可以固定浅色或深色，也可以恢复跟随系统。
- 即时且持久：切换立即生效，偏好存入扩展本地存储；跟随系统时响应运行中的主题变化。
- 无障碍不回退：焦点、错误、高亮、选择区域和禁用态不能只依赖颜色区分。

## 3. 视觉方向

主题面向需要长时间阅读论文、对照译文并向智能体提问的用户。视觉材料来自“纸张与墨水”，但不采用仿纸纹理：浅色模式使用冷白纸面与学术靛蓝；深色模式使用中性墨黑、石墨表面和低饱和淡靛蓝。

核心颜色：

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 阅读区背景 | `#f1f3f5` | `#111315` |
| 主表面 | `#fdfdfe` | `#1a1d21` |
| 抬升表面 | `#ffffff` | `#20242a` |
| 主文字 | `#16181d` | `#e7eaf0` |
| 次文字 | `#68707d` | `#a0a8b4` |
| 主色 | `#4f46e5` | `#a5a6ff` |

标志性处理是“灰纸原稿”：深色界面中 PDF 页面仍保持纸张、墨迹、照片和图表的原始明暗关系，但整体亮度降到约 72%，减少白页眩光。

## 4. 主题状态

公开类型：

```ts
type PdfThemePreference = 'system' | 'light' | 'dark';
type ResolvedPdfTheme = 'light' | 'dark';
```

- 存储键为 `pdf-workspace-theme`，保存用户偏好而不是解析结果。
- `system` 通过 `matchMedia('(prefers-color-scheme: dark)')` 解析，并监听 `change`。
- `light` 与 `dark` 固定主题，不随系统变化。
- 最终主题写入根元素 `data-pdf-theme`，偏好写入 `data-pdf-theme-preference`。
- 内容脚本接管页面时先按系统主题同步设置根元素，避免 React 挂载前出现明显闪白。

## 5. PDF 柔和暗化

深色模式的 Canvas 滤镜为：

```css
filter: brightness(.72) contrast(.92) saturate(.88) sepia(.04);
```

约束：

- 只应用于 `.pdf-page-canvas-wrap canvas`，不应用于外层容器。
- 文本选择层、区块高亮层、错误提示和译文不进入滤镜。
- 浅色模式的滤镜必须为 `none`。
- 主题切换使用 160ms 颜色过渡；`prefers-reduced-motion` 下取消过渡。
- 切换主题不触发 PDF.js 重绘，不改变 Canvas 位图尺寸、页高或渲染队列。

## 6. 切换入口

“更多操作”菜单增加“外观”分组，提供三个 `menuitemradio`：跟随系统、浅色、深色。当前项同时使用勾选标记、`aria-checked` 和主题色背景，不能只靠颜色表达选中状态。

## 7. 验收标准

- 三档主题可切换并持久化；跟随系统时无需刷新即可响应系统主题变化。
- 深色模式覆盖工具栏、阅读背景、译文、智能体、菜单、表格、代码、输入和状态反馈。
- 深色模式下 PDF Canvas 使用柔和暗化，浅色模式保持 `filter: none`。
- 图片和图表不出现全局反相导致的负片效果。
- PDF 文本选择、高亮联动、缩放清晰度和双缓冲生命周期不回退。
- 定向单元测试、类型检查、生产构建和 PDF 工作台 E2E 通过，并保存深色视觉基线。
