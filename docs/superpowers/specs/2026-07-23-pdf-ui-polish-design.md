# PDF 工作台现代化与易用性收口设计

## 背景

PDF 工作台已经采用编辑型极简视觉：中性画布、白色纸张、学术靛蓝、低卡片化结构以及逐页原文/译文配对。当前主要问题不再是视觉方向，而是完成度和交互细节：

- 论文智能体只有最大高度，空会话时面板按内容收缩，输入区无法稳定贴近视口底部；
- 窄屏工具栏会形成第二行，但覆盖式智能体仍按单行工具栏高度定位；
- 高频按钮点击热区小于 44px；
- 长论文缺少上一页、下一页和直接跳页，缩放状态不可见；
- 上传同意、失败恢复和初次读取状态仍带有浏览器默认控件感；
- Windows 下嵌套滚动条视觉重量偏高；
- 通用下载地址只显示 `download` 等弱信息标题。

## 目标

- 保持现有编辑型极简视觉系统，不引入新的组件库、远程字体或装饰性动效。
- 让桌面智能体稳定占满可用视口高度，消息区伸展，输入区固定在底部。
- 在窄屏下保持工具栏单行且不被覆盖式智能体遮挡。
- 所有主要交互热区达到至少 44×44px，并保留清晰焦点状态。
- 增加上一页、下一页、直接跳页和缩放百分比反馈。
- 统一加载、上传同意和失败恢复状态的按钮与反馈样式。
- 保留可见滚动能力，同时降低滚动条视觉噪声。
- 优先使用响应头文件名；通用下载路径回退到稳定、可识别的 PDF 标题。

## 非目标

- 不改变 PDF.js、MinerU、LLM、缓存和翻译调度逻辑。
- 不新增缩略图侧栏、全文搜索、下载或打印能力。
- 不新增深色模式；本轮仍以已批准的浅色编辑型极简主题为准。
- 不移除长译文正文和智能体消息区所需的独立滚动。

## 设计

### 工具栏

工具栏固定为 60px 单行布局，并使用共享的高度变量作为窄屏智能体覆盖层偏移。宽度逐步收缩时：

- 进度说明先隐藏；
- 标题允许省略，极窄宽度下隐藏；
- 智能体入口保留图标与可访问名称，极窄宽度下隐藏文字标签；
- 缩放百分比可隐藏，但缩放按钮和页码导航仍可用。

页码区域包含上一页、可输入页码、总页数和下一页。输入提交、失焦或 Enter 时把值限制在 `1..pageCount`，无效输入恢复为当前页。缩放区域显示整数百分比。

“更多”改为受控弹出菜单，支持按钮切换、点击外部关闭、选择操作后关闭和 Escape 关闭，并提供 `aria-haspopup`、`aria-expanded` 与 `role="menu"`。

### 论文智能体

桌面面板高度使用 `100dvh` 减去顶部偏移，保持标题、可伸展消息区和底部输入区三段布局。没有消息、等待和错误时显示轻量空状态以及三个建议问题；点击建议只填入输入框，不自动发送。

窄屏面板固定在 60px 工具栏下方并铺满剩余视口，不覆盖工具栏。

### 状态与按钮

- 初次读取显示居中的加载状态、简短说明和克制的进度指示。
- 上传同意按钮使用唯一主操作样式。
- 单页失败区的重试按钮使用主操作样式，详情和复制诊断使用次级样式。
- 所有按钮、菜单触发器、建议问题和详情摘要至少具有 44px 热区。
- 所有交互保持可见 `:focus-visible` 焦点环。

### 标题与滚动条

PDF 标题依次使用：

1. `Content-Disposition` 中的 `filename*` 或 `filename`；
2. URL 最后一个路径段；
3. 通用下载路径的稳定查询标识；
4. `document.pdf`。

没有 `.pdf` 扩展名的稳定标识补充 `.pdf`。译文正文、智能体消息和富文本横向溢出区域使用细滚动条，但不隐藏滚动条。

## 响应式与无障碍

- 1440px：原文、译文与展开的智能体保持三列，不相互覆盖。
- 800px：工具栏保持单行，展开智能体从工具栏底部开始覆盖剩余视口。
- 375px：无横向页面滚动；标题和次要文字逐步隐藏，页码、缩放和智能体入口仍可达。
- 所有新增图标使用内联 SVG，结构图标不使用 Emoji。
- 页码输入拥有可见标签或 `aria-label`，按钮拥有明确可访问名称。
- 加载与动态状态继续使用 `role="status"` 或 `aria-live`。
- 动效遵守 `prefers-reduced-motion`。

## 验收标准

- 智能体空状态和有消息状态下均占满可用视口，输入区位于底部。
- 800px 和 375px 下智能体不遮挡工具栏，页面无意外横向滚动。
- 工具栏和智能体主要按钮计算后的最小高度、宽度不小于 44px。
- 上一页、下一页、直接跳页和缩放百分比可用且具备键盘语义。
- “更多”菜单支持 Escape、外部点击和操作后关闭。
- 加载、上传同意和失败恢复状态不再显示浏览器默认按钮。
- 通用 `download?id=paper` 地址显示为可识别 PDF 标题。
- PDF 定向测试、类型检查、构建和 PDF 工作台 E2E 通过。
