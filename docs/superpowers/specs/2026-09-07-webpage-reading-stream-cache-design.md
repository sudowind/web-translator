# 网页阅读窗口、逐块流式与缓存优化

## 用户目标

默认正文按需翻译，前方约一屏预取；合批请求、完整块逐个显示、本地缓存复用，并测量实际 TTFT、首段显示与批次耗时。沿用当前网页 feature，主工作区保持本轮 release。

## 阅读范围与调度

- 优先 main、role=main、article，缺少正文标记时回退 body，并排除站点页眉、导航、侧栏、页脚与明确广告区域。文章内 header 的标题摘要保留。
- 当前可见块优先，沿阅读方向前方一屏作为低优先预取；滚动后稳定 400 毫秒再发新请求。滚动过程中不继续排空队列；跳转后重新计算窗口。
- 后台标签页停止发新批次，已完成译文保留。已发送请求不承诺取消可退费。
- 页面进度面板提供按需／整篇正文切换；整篇也不含站点导航等界面文字。关闭清理观察、滚动监听、计时器及译文。

## 流式协议

- 仍使用 chat completions SSE 与 JSON translations 数组，增量解析仅接受完整 id/text 对象，校验 id 与行内标记后发布。
- 页面按 sessionId 和块 id 拒绝跨会话、过期结果；最终响应再次校验。
- 传输中断保留已验证完整块，只将未完成块标记失败供重试。重复 id、未知 id 或最终结构冲突撤销该批增量结果，不写入缓存。
- PDF 保持原有整页响应接口行为，新增回调仅网页使用。

## 缓存

- 使用独立 IndexedDB，不修改 PDF 数据库版本。缓存只保存译文及散列标识，不保存原文、URL 或密钥明文。
- 标识包含页面地址（去锚点）、原文标记文本、源／目标语言、接口、模型、方言、凭据散列隔离及网页提示词版本。
- TTL 30 天、最多 2,000 条、约 8 MiB 译文字节，访问时更新最近使用；写入时淘汰过期与最旧条目。
- 同批同文复用结果；缓存异常降级在线翻译，不阻断阅读。面板提供清除此页缓存入口，清理时阻止在途结果回填。
- 与父元素文字样式完全一致的 SPAN 不再占用行内标记；链接、强调和差异样式继续保留。只有整批最终校验成功才持久化新结果，传输中断的完整块仅保留在当前页面。
- 清理命令同步递增内存 epoch，旧请求即使仍处于读取配置阶段也不能回填；保守地同时抑制其他页面已在途请求的缓存写入，不影响译文显示。

## 时间指标

从实际 HTTP 请求发出到首个非空 content delta 记录 TTFT，从请求发出到结束记录批次耗时。首段显示记录从启用到首个有效译文的渲染帧；缓存命中不计入模型 TTFT。保留当前会话最近 100 个请求样本，展示中位数、P95、样本数及首段时间；不虚构实测结论，不另发付费基准请求。

## 验证与边界

定向测试覆盖阅读窗口、滚动稳定、隐藏标签暂停、流式 JSON 跨片段与转义、无效 id 撤回、传输中断、缓存隔离／过期／淘汰／清理、耗时定义。隔离浏览器 E2E 使用可控 SSE 慢流，验证首块先于最终响应出现、离屏无请求、滚动预取和重开缓存命中。真实 action Popup／原生权限仍按人工门禁，不绕过工具边界。
