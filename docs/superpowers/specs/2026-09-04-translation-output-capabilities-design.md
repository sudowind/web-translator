# 翻译输出协议与能力配置

日期：2026-09-04
状态：已实现并通过自动化验收，真实接口待用户确认

## 目标

替代 Qwen 结构化输出补丁中的模型及域名白名单。所有 OpenAI 兼容接口共用翻译提示词、JSON Schema、SSE 解析和 ID 校验；能力不同不等于翻译契约不同。

## 行为约定

- 翻译配置新增自动、严格 Schema、JSON 模式。旧配置默认自动；自动在无有效记录时使用原有 JSON Object，不悄悄探测或重试正式文档。
- 用户点击翻译配置测试时，自动模式重新验证严格 Schema（使用现有最小 Hello 探针、流式、关闭思考）。只有 HTTP 400/422 的结构化错误明确拒绝 response_format/json_schema 能力时，最多降级测试一次 JSON Object。普通 400、错误 Schema 定义、鉴权、限流、超时、无效译文、缺失 ID 均不降级。
- 显式模式只测试所选协议，不自动降级。成功结果标记为“该模式请求及译文校验通过”，不声称探针可以证明服务端确实严格约束了所有输出。
- 结果按规范化 endpoint、精确 model、Provider 方言的 SHA-256 标识保存在扩展 local 存储；不保存 API Key、响应正文或文档。最多 32 项，30 天失效。重新测试先移除旧记录，失败不会写入成功能力；切换 endpoint/model/dialect 不复用错配记录。
- 正式翻译读取有效能力记录；显式模式优先。不增加正式翻译的重试次数，缓存不可用时自动模式保守使用 JSON Object。
- 测试不自动保存用户的连接设置；能力记录与连接设置分离。设置页展示当前能力、实际模式和测试费用边界，测试期间禁用字段，避免旧结果被当作新配置结果。
- 只保留 Provider 方言对思考参数的协议差异，不增加模型名称规则。不更改成功译文缓存。

## 安全与验证

HTTP 错误正文仅在内存中限量读取（16 KiB）用于判定，诊断仅传播稳定错误码，不记录正文。自动降级最多一次且只在用户发起的能力测试内。既有设置页消息来源及字段校验继续保留。

定向回归覆盖能力命中/失效/隔离、旧设置迁移、消息校验、模式选择、明确不支持与不可降级错误、真实客户端模拟 SSE 链路、设置页。独立复核后统一运行 check 与 E2E；不调用真实付费接口。

协议依据：[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)，2026-09-04 核对。JSON Object 只保证 JSON 语法，Schema 模式用于约束结构，支持情况需单独确认。
