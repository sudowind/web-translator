# 翻译输出能力重构验收报告

日期：2026-09-04
状态：实现、独立复核与自动化门禁完成，真实接口待用户确认

## 实现结果

- 移除 Qwen 模型及百炼域名白名单。所有兼容接口共用提示词、严格 Schema、SSE 解析、ID 校验。
- 设置页新增自动 / 严格 Schema / JSON 模式；旧配置缺省为自动。自动模式无有效能力记录时保持 JSON Object，正式翻译不增加探测或降级请求。
- 用户发起翻译测试时，自动模式先测试严格 Schema；仅明确的协议级 400/422 拒绝允许再测试一次 JSON 模式。普通 HTTP 错误、超时、译文校验失败、Schema 定义及关键字错误不降级。
- 能力记录按规范化 endpoint + model + dialect 的 SHA-256 标识隔离，保存在扩展 local 存储，30 天失效、最多 32 项。无凭据、正文或模型名称规则；重新测试清理旧记录，并发相同配置测试只运行一个探针。
- 设置页展示验证模式及时间、测试费用说明；测试期间禁止编辑，测试不自动保存连接设置。显式输出模式优先于记录。
- 新的不支持错误码归类为配置问题，提供修改模式提示，不自动重试。不变更成功译文或 PDF 解析缓存。

## 验证证据

- 通用模式 TDD：旧实现 4 项测试中 2 项失败，分别暴露未知模型无法显式使用严格 Schema，以及百炼模型被隐式特判。
- 实现初轮定向 Provider / 设置测试 12 文件、122 项通过；类型检查通过。
- 设置交互、错误诊断及集中修复后的定向测试 15 文件、133 项通过；后续误降级最小测试 18 项通过，能力探测/正式客户端串联及并发测试 14 项通过。
- 独立复核发现 1 项 Important：宽泛关键词匹配可能把 Schema 子关键字错误误判为协议不支持。已改为明确协议主语整句匹配、排除嵌套 Schema 参数，并加入原复现及歧义回归。同一 reviewer 聚焦复核已关闭，无待修 Important / Critical。
- 最终 `npm run check` 通过：TypeScript、65 个测试文件 / 458 项测试、WXT 生产构建、产物验证。Vitest 26.63 秒（transform 5.92 秒、setup 3.18 秒、import 累计 24.83 秒、tests 8.13 秒、environment 累计 30.07 秒；并发累计值不是墙钟总时长），WXT 5.461 秒。产物验证 Unicode noncharacter=0、静态 host 权限=0、静态 content script=0。
- `git diff --check` 通过。验证对应 dev 工作区未提交修改；未主动提交或推送。
- 最终 `npm run test:e2e`：12 项通过、1 项默认跳过，耗时 59.0 秒。通过用例覆盖授权后的 PDF 接管、解析/翻译/智能体、76 页长文档、arXiv 缓存恢复、失败诊断、上传同意及网页翻译。跳过项为需显式启用的真实 arXiv 网络样本；这些测试不代表原生权限弹窗或 action Popup 人工验收。
- 76 页长文档回归：首次可读 1949.1 ms、挂载译文正文 5 个、初始 Provider 页请求 4 个、最大渲染至提交 89.8 ms；满足现有性能断言。
