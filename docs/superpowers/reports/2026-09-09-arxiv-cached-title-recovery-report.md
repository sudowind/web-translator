# arXiv 旧缓存标题恢复补充报告

用户报告 `https://arxiv.org/pdf/2510.12403#page=73` 仍显示文件名。上一版仅依赖首页开头一级标题，未覆盖旧结果缺失层级的情况。用户浏览器连接失败，未直接读取其缓存，不能将这一推断写成已确认的实际缓存结构。

已从公开 arXiv 页面与一次真实 Node fetch 核验 `citation_title="Robot Learning: A Tutorial"`、`citation_arxiv_id="2510.12403"`。后续新增函数真实网络复测遇连接失败并返回空值；网络不稳定不作为读取成功证据。

## 修复

功能提交 `5d520bc`，release 合并代码提交 `39ca94f`。

- 新增独立标题补齐消息：仍是文件名的缓存通过官方 arXiv 引用元数据恢复标题，保存文档与历史。不重新解析、调用模型或替换 UI 全文模型。
- 标题异步加载，不阻塞第 73 页阅读恢复、不重启翻译调度。失败保持文件名，下一次打开可再尝试。
- 请求固定 arxiv.org 主机、合法论文编号、无 cookie、禁止重定向、4 秒超时及 256KB 上限，校验返回论文编号。
- 独立复核发现管理页清除全部缓存未使在途标题失效，已接入服务全局 generation 和串行清理并补回归；清库失败的读屏障恢复也已修复。无未关闭 Important。
