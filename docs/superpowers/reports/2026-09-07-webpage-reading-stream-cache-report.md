## 本轮行为

- 默认识别正文，只翻译可见范围及阅读方向前方约一屏；滚动稳定 400 毫秒后重算，后台标签页不发新批次。已译段落回看继续保留。
- 排除导航、侧栏、页脚、站点页眉和明确广告标记，文章内部标题保留。面板可切换整篇正文翻译。
- 保持小批请求；SSE 中完整且通过 id／行内结构校验的块先显示。传输异常保留已完成块；协议冲突撤回该批，只有缺失或失败块需要重试。
- 本地独立 IndexedDB 缓存按页面、原文、配置和协议版本散列隔离，30 天有效、最多 2,000 条及约 8 MiB 译文。支持同批同文合并、同样式 SPAN 标记精简、清除此页缓存；失败批次不持久化。
- 性能统计显示首段时间、缓存命中，以及当前会话最近 100 个请求的 TTFT／请求耗时中位数、P95、样本数。TTFT 从实际 fetch 开始计时到首个非空 content delta；缓存命中不计作模型 TTFT。未发起用户模型付费测速，真实延迟需使用时累积。

## 人工验收与已知边界

自动化使用独立、预授权测试扩展与本地模拟服务，真实 HTTP 流用于验证提前显示，不代表用户模型翻译质量或真实 TTFT，也不代表原生 action Popup／activeTab 授权门禁通过。

用户需在 Chrome 扩展页重新加载原扩展，再刷新文章页面并点击翻译。此前已确认工具不能控制该内部扩展页，本轮不重复探索绕过方式。验收时可检查滚动前正文下方没有被全部请求、向下阅读时补译、性能统计，以及关闭后原页面恢复。

正文识别仍以语义标签为主；缺少 main／article 的复杂网站回退 body，广告过滤仅覆盖明确语义或 data-ad／data-ad-slot 标记，不承诺所有站点模板识别。已发送请求可能仍产生费用；流式改善首段可见时间，不直接减少输出 token。嵌套滚动区的方向预测目前以文档滚动方向为准。
